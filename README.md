# Site RUMIÁ — GitHub Pages

Este pacote é o site pronto: um único \`index.html\` (CSS, JS e fontes embutidos).

## Publicar em 4 passos
1. Crie um repositório **público** no GitHub, ex. \`rumia-site\`.
2. **Add file → Upload files** e envie \`index.html\` e \`.nojekyll\` (arquivos na raiz do repo).
3. **Settings → Pages** → Source: **Deploy from a branch** → Branch: \`main\` / \`/ (root)\` → **Save**.
4. Em 1-2 minutos o site estará em \`https://SEU-USUARIO.github.io/rumia-site/\`.

Domínio próprio: Settings → Pages → Custom domain (ex. rumia.com.br) e aponte o DNS para o GitHub.

Para atualizar o site depois, basta enviar um novo \`index.html\` por cima.
